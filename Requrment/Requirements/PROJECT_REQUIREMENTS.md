# University Library Management System
## Project Requirements

### 1. Introduction
This document describes the functional and non-functional requirements of the proposed system.

### 2. Functional Requirements

**FR-01: User Login**
The system shall allow authorized users to log in.

**FR-02: Book Management**
The system shall allow librarians to add, update, delete, and view book records.

**FR-03: Student Management**
The system shall maintain student information.

**FR-04: Book Search**
The system shall allow users to search for books.

**FR-05: Book Issuing**
The system shall record books issued to students.

**FR-06: Book Returning**
The system shall maintain records of returned books.

**FR-07: Overdue Management**
The system shall identify books returned after their due dates.

**FR-08: Membership Management**
The system shall maintain library membership records.

### 3. Non-Functional Requirements

**NFR-01: Usability**
The system should be easy to understand and use.

**NFR-02: Performance**
The system should respond to user requests efficiently.

**NFR-03: Security**
The system should protect library information from unauthorized access.

**NFR-04: Reliability**
The system should maintain accurate and consistent records.

**NFR-05: Maintainability**
The system should be easy to update and maintain.

### 4. Conclusion
These requirements define the basic functions and quality expectations of the proposed University Library Management System.
