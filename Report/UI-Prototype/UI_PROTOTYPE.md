# University Library Management System
## UI Prototype

### 1. Introduction
This document describes the proposed user interface of the University Library Management System.

### 2. Login Page
- Username field
- Password field
- Login button

### 3. Dashboard
The dashboard provides an overview of library activities.

### 4. Dashboard Features
- Total books
- Registered students
- Issued books
- Returned books
- Overdue books

### 5. Book Management Page
- Add new books
- Update book details
- Delete book records
- Search available books
- View book information

### 6. Student Management Page
- Register students
- Update student information
- View student records
- Manage memberships

### 7. Book Issuing Page
- Select student
- Select book
- Enter issue date
- Enter due date
- Confirm book issuing

### 8. Book Returning Page
- Search issued book
- Verify student information
- Record return date
- Update book availability

### 9. Overdue Management Page
- View overdue books
- Identify late returns
- Maintain overdue records

### 10. Conclusion
The proposed interface aims to provide simple navigation and easy access to library functions.
